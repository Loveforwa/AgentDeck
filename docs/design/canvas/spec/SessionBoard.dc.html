5 · 规则
情况怎么做 关掉父 session 的窗口照样问 “Stop and close”。子 session 不受影响，标签变 “(stopped)”；N2 停靠解除，子终端平铺。 关掉子 session 的窗口父的 “N sessions” 减一；左边栏里这一行留着（Stopped），能 Reopen。 Reopen 一个子 session开回原来的框；父还开着时停靠回 N2 侧边栏（只限同一个框、open_terminals 开的）。 父 session 在别的框、别的项目标签照样显示；关系线跨框画；父的框不在白板上时单击标签打开左边栏定位。 很多子 session标签只写个数；关系线最多画 8 条，更多的看左边栏。 “在等你”父子关系不改变计数和 ⌘J；收件箱（CR1）里的一条可以写 “from claude · lead”。 撤销（X10）撤销关闭照旧放回窗口；Session 不进撤销，关系本来就还在。
