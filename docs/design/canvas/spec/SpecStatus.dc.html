6 · 终端状态与提醒

每个终端都有一个状态，显示在标题栏的点和文字上，并汇总到工作区框、顶栏和系统通知，保证你不用盯着每个窗口也知道谁在等你。

六种状态的标题栏

“lead”只是用户用“Rename”给终端起的名字，应用不判断谁是主力；没改名时只显示 agent 名。

什么时候进入哪个状态
状态什么时候进入标题栏文字 启动中刚创建，程序还没有任何输出Starting 运行中收到“开始处理”的通知，或有新输出Running · 4m（这一轮多久） 等你收到“需要批准”的事件；或 agent 用它的提问工具向你提问（例如 claude 的 AskUserQuestion）。只是一轮说完不算，算空闲Needs approval · 3m 或 Needs reply · 3m 空闲一轮结束；没有通知能力的程序 3 秒内没有新输出Idle · 12m 已退出进程以 0 退出Exited 出错进程以非 0 退出，或启动失败Error · exit 1

时间写法：不到 1 分钟写“now”，不到 1 小时写“4m”，不到 1 天写“2h”，更早写日期“Oct 21”。每 30 秒更新；悬停显示准确时间，如“Started at 14:32”。

状态从哪来
程序运行中 / 空闲等你批准等你回复接法 claude✓✓✓钩子（hooks）：UserPromptSubmit、PermissionRequest、Stop 等。启动时用 --settings 临时加上，不改你自己的配置 codex✓✓✓钩子（hooks）：本机 codex 0.159 已有 PermissionRequest、Stop 等事件；旧版本只能用 notify，只知道一轮结束 其他 agent✓可配置—tmux 的输出活动判断运行中和空闲；可在设置里给它配一句“等你”的文字，例如“(y/n)”，停下 3 秒且最后几行出现这句才算等你 Shell 和其他程序✓——只用 tmux 的输出活动；退出码判断已退出和出错

钩子触发时运行 AgentDeck 自带的一个小命令，它读 tmux 给每个终端设的环境变量 AGENTDECK_TERM，把“哪个终端、什么事件”发给应用。所以状态不靠识别屏幕文字，看不见的终端也是准的。agent 升级改了钩子格式时，这个 agent 自动退回到“其他 agent”那一行的做法，并在 Settings › Agents 里提示。

批准规则
  • 只处理“批准”类请求：claude、codex 的 PermissionRequest 事件，或配置了“等你”文字的其他 agent。agent 向你提问（Needs reply）、让你在几个选项里选，都不算，永远留给你。
  • 入口：同时有 2 个及以上在等批准时，顶栏的“waiting”旁出现“Approve all…”，⌘⇧J 相同。一定先弹列表，写清每条是哪个 agent、哪个工作区、要运行什么，确认后才批准。
  • 看起来有破坏性的命令默认不勾：rm -rf、git push --force、git reset --hard、DROP / TRUNCATE、FLUSHDB / FLUSHALL、改动 .env 等。名单在 Settings › Approvals 里可以改。
  • 只选“这一次允许”，从不选“以后都允许 / don’t ask again”，不会改动 agent 自己的权限设置。
  • 批准的做法：给那个终端的 tmux 窗格发 agent 对应的“允许一次”按键（claude 是回车选第一项 Yes，codex 是 y，其他 agent 在设置里配）。发完 2 秒内状态没离开“等你”，就在那一条上标“Couldn’t approve”，留给你手动处理。
Auto-approve（按工作区开）
  • 默认关闭。右键工作区框 › “Auto-approve”打开；打开后框标题显示“Auto-approve”，再点一次关闭。只影响这个框里的终端。
  • claude 和 codex 在钩子里直接回答“允许”，终端里不会出现确认提示；其他 agent 等提示出现后由 AgentDeck 发按键。
  • 破坏性名单里的命令照样停下来等你，提问和多选也照样等你。
  • 每次自动批准都弹一条轻提示，并记进这个工作区的记录（右键框 › “Approval history”），可以事后查。
  • 想让某个 agent 全程不问，也可以直接用它自己的模式（例如 claude 的 --permission-mode、codex 的 --full-auto），在 Settings › Agents 的启动参数里加。Auto-approve 是中间档：自动，但挡住危险命令、留记录。

提醒规则
  • 窗口：状态点变橙；窗口未聚焦时边框也变橙。
  • 工作区框：标题栏右侧显示“1 waiting”。
  • 顶栏：“1 waiting”按钮，单击依次跳到每个在等你的窗口，⌘J 效果相同。
  • 应用在后台：发系统通知（设置里可以关），程序坞角标显示在等你的数量。
  • 聚焦一个在等你的窗口后，橙色边框消失，状态点仍是橙色，直到 agent 继续运行。
  • 终端拉小成摘要卡时，在等你的摘要卡同样是橙色。
