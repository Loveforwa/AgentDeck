15 · 项目框：一键排版，新建时自动排

2026-10-26 定 N12 · IS-87

一个项目框里开了好几个 agent 之后窗口容易散乱。框标题右上角加几个小图标：点一下把框里的窗口排整齐（紧凑网格、并排、上下叠），框缩到正好装下。再加一个开关：开着时，在这个框里新开、关掉窗口都自动按上次的排法重排，不用再手动拖。

新开的 pi 直接放进网格的下一个格子（虚线是它落下的位置），别的窗口不动；关掉一个时后面的往前补。拖动窗口还是可以的：拖完不会被弹回去，下一次新开或关掉时才重排。
开关按框记，随白板保存，默认关。 开着时：在这个框里新开终端或网页（New terminal、agent 用 MCP 开的、W5 的 Open new）、关掉窗口，都按这个框上次用的排法重排一次；没点过排法时按 Tidy。 悬停写 “Auto-arrange is on · Tidy”。在框的右键菜单里也有一项 Auto-arrange new windows（打钩）。 只在新开、关掉时排，不在拖动、改大小时排，免得窗口在手底下跳。
4 · 规则
情况怎么排 排哪些只排这个框里的窗口，不跨框。放大中的、收起的子终端不动。 连在一起的算一块窗口组（lead、侧边栏、停靠的子终端）、开着的后台 agent 面板（画板 13）、窗口下面的书签和 Usage 条都跟着自己的窗口算一块，不拆开。 顺序按排之前的位置：先上后下、先左后右；新开的排在最后。 框的大小排完框缩到正好装下（四边留 16，标题下面 36）；变小、变大时挤开或让回旁边的框（V3 的规则）。点图标排版时框的右上角不动，刚点的图标还在指针底下，可以接着点别的排法（2026-10-26 定）；Auto-arrange 自动排时左上角不动。 撤销点一次排法算一步，⌘Z 回到排之前。Auto-arrange 自动排的那次和新开窗口算在一起，不单独记。 数字窗口之间 20（和不重叠的间距 GAP 一样）；Columns 的宽度不小于窗口的最小宽度，放不下就换到下一行。
不做的
不改终端里的字号；不把窗口拉成很小的格子（小于最小尺寸时换行）。 不一次排整块白板（以后可以在白板的右键菜单里加 Arrange all frames）。
已定（2026-10-26）
Tidy 不改窗口大小。 Auto-arrange 开着时，关掉窗口也重排。
