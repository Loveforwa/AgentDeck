3 · 白板

承载所有工作区和窗口的背景板。背景是 20px 间距的浅色点阵，缩放到 50% 以下时点阵隐藏。

右键新建终端

在白板空白处右键

“New terminal ▸” › claude

终端出现在右键的位置，已经聚焦，可以直接打字

把终端拉小，放下更多窗口

按住终端的右下角（任意一条边也可以）

变成摘要卡：只显示最后 3 行和状态，在等你的仍然是橙色；腾出来的地方可以放别的窗口

恢复到拉小之前的大小并聚焦，可以直接打字；再拉小又变回摘要卡

操作与表现
  • 两指滑动 / 滚轮：平移白板。光标停在已聚焦的窗口上时，改为滚动那个窗口的内容。
  • 空格 + 拖动 / 中键拖动：在任何位置平移。有终端聚焦时空格会输入到终端，只能用中键或两指。
  • 想放下更多窗口：拖窗口或框的边、角，直接改大小，不靠缩放白板。
  • ⌘ + 滚轮：缩放整块白板（25%–200%），作为备用；不响应双指捏合。
  • 单击空白处：取消选中、取消聚焦，关闭菜单。
  • 在空白处按住拖动：拉出选框，完全框住的窗口和框被选中；按住 ⇧ 追加。
  • 右键或双击空白处：弹出菜单（“New terminal ▸”“New browser”“New workspace…”“Add project…”“Show all”），新建的东西放在这个位置。双击不会直接创建，避免误触。
  • 拖入 .html 文件：在放下的位置打开网页窗口。
  • 拖到视口边缘：白板自动向那个方向平移，越靠近越快。
  • ⌘1 “Show all”（最大 100%）；⌘0 缩放到 100%。
  • 终端被拉到小于 320×200：换成摘要卡（最小 110×60），只显示最后 3 行和状态；单击恢复到拉小之前的大小并聚焦。网页窗口拉小时同理，只显示标题和地址。字不跟着缩小，所以不会发糊。摘要的最后几行直接从 tmux 读取，不需要为它打开终端界面。
  • 用 ⌘ + 滚轮把整块白板缩到 75% 以下：所有终端同样换成摘要卡。
  • 不在视口里的终端：不打开终端界面，只在 tmux 里继续运行；移进视口时再接上显示。
  • 空白状态：视口中间写“Add a project to get started, or right-click to open a terminal.”，下面两个按钮：“Add project”“New terminal”。
