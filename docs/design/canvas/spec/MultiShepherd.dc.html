3 · “tmux 多 pane 复制不顺手”在 AgentDeck 里是什么情况

AgentDeck 底下也是 tmux，但每个终端窗口是自己的一个 xterm.js，接自己的一个 tmux 会话（tmux-host 每个终端 new-session，不分屏）。所以 tmux / herdr 那种“一个终端里切成几块、拖选会跨过分隔线、要进复制模式”的问题在这里不存在。剩下的不顺手在下表最后三行。
