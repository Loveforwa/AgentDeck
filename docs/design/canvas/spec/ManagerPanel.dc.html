3 · 每一部分
部分内容和规则 New菜单：Terminal ▸（装了的 agent + Shell）、Browser、Workspace…（⌘⇧N）、Add project…。新开的放在当前聚焦的工作区框里，没有聚焦就是白板视口中间。和右键白板的菜单是同一份。 Search（没有快捷键：⌘K 是清屏）面板顶上变成输入框，搜会话标题、第一条消息、分支、窗口名；搜索时全部展开、只留命中的；Esc 退出。 NEEDS YOU有在等你（黄）或出错（红）的终端才出现，按等的时间排，行底 --attention-soft。⌘J 依次跳这里的行；⌥⌘1–9 跳到这一段的第 1–9 行（原来 Agents 视图的快捷键搬过来）。 PINNED你置顶的会话、项目、工作路径，按置顶的先后，拖动可以换顺序。随白板保存。会话被关掉了照样留着（变成可以 Resume 的一行）。 项目 → 工作路径和现在的 HISTORY 一样：项目（可折叠）→ 主目录和各 worktree（▾ / ▸ + 分支 + 数量）→ 会话，最近的在前，每组 5 条后 “Show n more”。不再按 agent 分小标题：每行前面一个 agent 身份色的小方块。开着的会话在前、带灯；Other folders（不在项目里的）在最后。 一行灯（开着才有：运行中绿、等你黄、出错红、空闲空心）· agent 小方块 · 标题 · 右边时间（开着的写状态和时长，像 “Waiting · 2m”）。单击：开着的跳到窗口（同 ⌘J 的走法），关掉的在它的工作区框里 Resume。
4 · 原来的两个面板去哪了
原来合并以后 右边 BOARD（Board 视图：项目 → 工作区 → 窗口）并进左边面板：开着的窗口就是带灯的那几行。网页窗口也列在它所在的工作路径下（小窗口图标，不写时间）。 右边 Agents 视图（按状态分组）变成顶上的 NEEDS YOU 一段；RUNNING、IDLE 不再单独分组，看每行的灯。 左边 HISTORY就是这个面板的主体；标题改成白板名。 右边面板只留源代码管理。什么都没聚焦时写 “Focus a terminal to see its changes.”，⌘B 照旧开关。
