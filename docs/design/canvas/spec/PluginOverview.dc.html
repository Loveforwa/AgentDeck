PL0 · 插件：入口和规则

2026-10-25 定

插件是贴在终端（或整个工作区框）上的小功能，开着时旁边有一个看得见的标记。第一批两个：Auto-approve（PL1，底边左侧的红色小书签）和 Usage 用量记录（PL2，贴在上方或下方的细长条，我们自己读各 agent 的记录）。规则和登记表在仓库的 docs/plugins.md（插件手册），做插件前先读。

右键终端标题栏，菜单中间有一组 PLUGINS，直接列出插件，不套子菜单。打钩表示在这个终端上开着，再点一次关掉。 开着就有标记：Auto-approve 是底边左侧的红色小书签（需要你处理时临时变橙，写 Needs you），Usage 是贴在上方或下方的细长圆角条。 用不了的插件项灰掉，并写原因。 右键工作区框也有这一组，列出能贴在框上的插件（目前只有 Auto-approve）。 开关状态随白板保存，重启后还在。
每个插件先回答：能贴在哪些东西上

白板上有终端窗口、网页窗口、工作区框（项目框，里面放终端和网页），还有整块白板。每个插件开工前要先定它能贴在哪几种上，写进插件手册的登记表。

插件终端窗口网页窗口工作区框白板标记 Auto-approve（PL1）✓ claude、codex、omp、pi✗✓ 框里所有终端✗终端底边左侧的红色小书签 “Auto-approve” Usage（PL2）✓ 读得到数据的 agent✗以后（项目用量）以后（整台电脑）终端上方或下方的细长圆角条，可拖

贴在框上和贴在窗口上同时存在时：在窗口上单独关掉，只关它自己；在框上关掉，框里的都关。Skills · MCP 不是插件，放在源代码管理面板里（画板 12 · N9）；子 agent 窗口组是 v3 的 N2（侧边栏）。
