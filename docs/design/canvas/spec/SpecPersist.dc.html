9 · 保存与重启

布局一直自动保存。终端进程由 tmux 托管，所以“关”分三种：只关窗口（应用和 agent 都在后台继续）、退出应用（agent 继续，应用不在）、全部停止（agent 也结束）。全部停止或电脑重启后，下次打开能把上次的工作区和 agent 对话接回来。

三种关闭方式
关闭方式怎么触发AgentDeck终端和 agent提醒再打开 Close window红色关闭按钮、⌘⇧W留在后台，不画任何界面继续跑系统通知和程序坞角标照常单击程序坞图标，立刻回来，什么都不用重连 Quit⌘Q退出在 tmux 里继续跑没有自动接上，历史输出和状态都在 Stop all and quit应用菜单，或退出对话框里的按钮退出全部结束；先记下每个终端的命令、目录和 agent 会话没有问一次“Restore all”：agent 接回原来的对话，Shell 在原目录打开 电脑重启——tmux 跟着结束；记录早已写好—同上

记住什么
  • 一直自动保存，没有保存按钮，改动后半秒内写入：白板的平移缩放位置、所有工作区框、所有窗口的位置大小、类型、名字、网页地址、右侧面板的宽度和开关。
  • 每个终端还记下：启动命令和参数、工作目录、是哪个 agent、agent 的会话 id（claude 是我们启动时传的 --session-id，codex 从钩子事件里读）。
  • 工作区就是磁盘上的文件夹，总是恢复。文件夹不见了，框显示“Folder not found”，提供“Locate…”和“Remove”。
怎么恢复
  • agent 用会话 id 精确接回：claude --resume <id>、codex resume <id>。不用“继续最近一次”，这样同一个目录里有两个 claude 也不会接错。
  • 不支持续聊的 agent 重新启动，标题栏注明“New conversation”。
  • Shell 在原目录打开，把它当初的启动命令（例如 pnpm dev）填进输入行，不自动运行，按回车才跑。
  • 网页窗口重新加载原地址。
  • 选“Not now”后，停止的终端以“Stopped”卡片留在原位，可以单独“Restore ▾”，也可以直接关掉。
关闭窗口的细节
  • 窗口关掉时，界面整个销毁（所有 xterm 和白板都不渲染），只留主进程连着 tmux 和钩子，占用很小。再打开时从内存里的状态重建，不到半秒。
  • Settings › General › “When you close the window”：“Keep running in the background”（默认）或“Quit AgentDeck”。
  • 菜单栏图标可选：显示在等你的数量，单击打开窗口。
  • AgentDeck 退出期间没有提醒；重新打开后，在等你的终端立刻显示为橙色。
