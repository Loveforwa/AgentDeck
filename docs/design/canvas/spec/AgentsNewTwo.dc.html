3 · 预计到哪一档：档位从能力报告算出来，不写死
第一档 · 深做条件：status、approval-wait 是 A（钩子或插件，不认屏）；first-prompt、resume、session-id 至少 B；能挂 AgentDeck MCP 或有 shell-tool。能做：集群 Lead / Worker、Auto-approve 不靠按键、收件箱里直接 Approve、用量。现在：claude、codex。
预计：OpenCode（L2 过了以后，排在集群第一期之后；quota、subagents 两格先是 Partial）
第二档 · 跟上条件：有扩展报状态，但批准或会话 id 有一部分靠按键、推断。能做：同第一档，C 档的项版本一超过核对版本就自动关（AH3）。现在：omp、pi。
第三档 · 通用条件：状态只看输出活动。能做：普通终端；自由模式的子 session（不带 crew 和 session 命令，五家都行）；能跑 shell 的可以用 agentdeck 命令行进集群。黄灯不亮，收件箱里看不到它在等你，悬停写 “Status from terminal activity · no hooks”。现在：kimi。
预计：Hermes。已定不往 ~/.hermes 装插件，停在通用档
