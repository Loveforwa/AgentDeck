7 · 网页窗口

在白板上显示 dev server 页面或本地 HTML 文件，和产生它的终端放在一起。默认大小 640×420。

结构图
1后退、前进、刷新（⌘[ ⌘] ⌘R）
2地址栏：单击或 ⌘L 编辑，↩ 打开，Esc 取消；只接受 http、https 和本地文件
3来源：哪个终端打开的它
4“Open in browser”：用系统浏览器打开当前地址
5放大（同终端）、关闭（直接关闭，⌘Z 可以恢复）
6网页内容；聚焦时滚动网页，未聚焦时滚动会平移白板

怎么打开
  • 单击终端输出里的本地地址或 .html 路径（见 5 · 终端窗口）。
  • 右键白板或框 › “New browser”：起始页列出这个工作区的终端里出现过的本地地址，单击打开。
  • 从访达拖入 .html 文件；⌘T 新建，规则同 ⌘N。
边界情况
  • 页面拒绝被嵌入显示：内容区写“This page can’t be shown on the board.”，按钮“Open in browser”。
  • 本地 HTML 文件被删除：显示“File not found”和路径。
  • 需要登录的页面在白板里可能保持不了登录状态，MVP 里用“Open in browser”；独立窗口模式放在 v0.2。
