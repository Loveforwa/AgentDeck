U0 · 不是每件事都要一个终端：后台任务（Run）和任务面板

2026-10-31 提议，待你确认

你 10-31 说的：如果每件事都要在白板上开一个 code agent 终端，白板上就全是终端，集群也摆不下、看不清；有的人只想要一个对话窗口，后台一队 agent 在跑，对话只用来问进度、改方向。所以把“白板上放真终端”从必须改成三种露面方式之一：要聊、要盯的开终端；只要结果的做成后台任务（Run），在容器或 tmux 里用 agent 的非交互模式跑，白板上只是一张卡片，或者干脆不上白板；看进度用任务面板：agent 按这个场景从一套固定零件里拼出来，数据由 AgentDeck 实时填，你要改样子时才再花 token。骨架不变：每一件事仍然是一条 Session（S0），有父子、有笔记、能交接。

3 · 面板怎么来：agent 用固定零件拼一份说明，AgentDeck 画、实时填数
WHAT THE AGENT WRITES · agentdeck panel save overnight.json

英文（给 agent 写的）。只写“摆什么、绑哪份数据”，不写数，也不写颜色和样式。
零件是固定的一套：stats、table、list、progress、log-tail、diff-summary、checklist、markdown、actions。样子全来自组件库（design-tokens），颜色只表达状态，和别处一致；agent 不能写 HTML、CSS、脚本。 数据是绑定，不是抄进去：runs、crew.tasks、issues、sessions、flows、usage 这些数据源由 AgentDeck 实时填。面板画好以后不再花 token，只有你说“换个样子”时 agent 才再写一份。 按钮只能调 AgentDeck 的动作：打开、回答、停、交接、重排。每个动作走它原来的关卡：对外发言照样进收件箱，Merge into main 照样只有你点，Auto-approve 碰不到。 谁能写：AgentDeck 里的任何终端都能 agentdeck panel save（只是存一份草稿）；你点 Save as view 才进左边栏，Pin 了每次打开都在。也能存进仓库 .agentdeck/panels/，团队共用。 手机上也能看：同一份说明，手机页（R1）按窄屏排一遍，不用另做一套。
4 · 现成的做法（2026-10-31 查）
做法是什么对我们结论 A2UI（Google，开源）agent 发一份声明式的 UI 说明（用哪些零件、绑哪些数据），客户端用自己的原生零件画；不传可执行代码和我们“只能用组件库零件、颜色只从 tokens 来”的规矩最合；agent 写不出越权的按钮照这个路子做，格式自己定一份更小的 MCP Apps（MCP 扩展，Anthropic、OpenAI 都支持）MCP 服务器给一段 HTML（ui://），宿主放进沙箱 iframe 里显示什么都能画，但样子和颜色管不住；agent 现写 HTML 要花很多 token，每次刷新都要重写不选；以后有人做了现成的 MCP App，可以当一种窗口开 AG-UI（CopilotKit）agent 和界面之间的双向传输协议，不管画什么我们的 agent 和界面在同一台机器，走 AgentDeck 自己的命令行和事件就够不用 GitHub Mission Control（Agent HQ，2025-10）一个地方派活、盯进度、改方向、看结果，网页、VS Code、手机、命令行都有说明“一个总控视图 + 后台一堆 agent”是对的方向；它是固定的页面，不按场景变对标它的“一处看全”，再加上按场景拼 Sandcastle（mattpocock，MIT）agent 在沙箱里用非交互模式跑，结果是分支上的提交；Claude Code、Codex、Pi 能接着上一段会话 resume证明“不开 TUI 也能做完一整件事”；Take over 用的就是各家的 resume见 U1、U2
5 · 数据：Run 是 Session 的一种，面板是一份说明
字段（contracts，单独提交，只加不改）意思 Session.runtimetmux（现在）或 container（U2） Session.modeinteractive（真 TUI）或 headless（非交互模式，一轮一轮跑） Session.surfaceterminal · card · hidden：白板上怎么露面，随时能换 Runheadless Session 的一次执行：第几轮、完成信号、检查结果、日志文件、目标分支、提交、token RunRule卡住了怎么办：重试几轮、交给哪一家、停下来问你 PanelSpec标题、范围（项目 / 集群 / 标签）、零件列表、谁写的、版本；存在数据目录，可存进仓库
headless 的 Session 照样有 Session 笔记（S3）、按天的日志（S4）、父子关系（谁派的）、交接（SE6），所以“后台跑的”不是另一套东西，只是没开窗口。 左边管理面板（MP）照样一行一个：开着窗口的有灯、单击跳过去；后台跑的也有灯，单击打开它的卡片；不上白板的单击打开它所在的面板。 集群（C2）的模板模式里，Worker 默认是卡片，Lead 和要你看的 Reviewer 是终端；白板上一个集群框不再塞满终端。
