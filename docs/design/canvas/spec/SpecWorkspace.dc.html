4 · 工作区框

白板上的一个框，代表“这个仓库的这个分支”。框里的终端都在这个目录里运行，右侧面板显示的也是这个目录的 git 状态。

结构图
1项目名
2分支名，单击打开切换分支菜单（规则见 8 · 源代码管理面板）
3有窗口在等你时显示数量；平时为空，不显示改动行数之类的信息
4这个工作区里的终端和网页窗口；没有窗口时中间显示“Right-click to add a terminal”
5拖动边或角改大小，不能小于里面窗口占的范围再加 16px

删除工作区

选中框，按 Delete

默认只从白板移除

框消失，目录和分支都还在；可以撤销

删除工作区并删除目录 另一种情况

有未提交的更改时，删除按钮不可用

勾选后才能删除；分支默认保留

新建规则
  • 入口：右键空白处 › “New workspace…”；顶栏“Projects ▾” › 某个项目 › “New workspace…”；⌘⇧N。后两种对话框出现在视口中心。
  • “Project”下拉里最近用过的在前，最后一项是“Add project…”。
  • 项目主目录已经在白板上时，“Main folder”不可选，旁边写“Already on board”。
  • “Existing”只列出没被其他工作区检出的分支。
  • worktree 目录名由分支名生成，/ 换成 -，例如 feat/oauth 对应 …/api-server/feat-oauth。
  • 新分支名已存在：在对话框里提示“Branch oauth already exists”，并提供“Use existing branch”。
操作规则
  • 单击标题栏：选中这个框，右侧面板切到这个工作区，不改变聚焦的窗口。
  • 双击标题栏：缩放并平移，让这个框占满视口（最大 100%）。
  • 右键标题栏：“New terminal ▸”“New browser”“Open in editor”“Reveal in Finder”“Copy path”“Delete workspace…”
  • 右键框里的空白处：和白板的右键菜单相同，但新建的东西放进这个框。
  • 框和框可以重叠，最后选中的在上面；框不能嵌套。
删除与边界情况
  • “Remove from board”：结束框里的终端，关闭网页窗口，目录和分支保留；以后可以在右侧面板的“Repository”区加回白板；可以 ⌘Z 撤销。
  • 删除目录不能撤销。项目主目录工作区只有“Remove from board”。
  • 创建 worktree 失败：框里显示 git 的错误，按钮“Retry”“Delete”。
  • 目录在命令行里被删掉：框显示“Folder no longer exists”，按钮“Recreate”“Remove from board”。
