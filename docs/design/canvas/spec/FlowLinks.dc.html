2 · 代码变了以后，图还对不对：三档检查
检查怎么做什么时候结果 锚点原文还在不在按 anchor.text 在文件里找，离原来的行最近的那处；找到但行号变了就自动改行号。open_terminals 实测：主检出目录里 19 步原地、3 步挪了、0 步失效文件保存后（防抖）、切分支、打开窗口绿（含 +n）或红 Stale 锚点所在的函数改过没有git diff 的改动块和锚点所在符号的范围（codegraph 有索引时用它的 start_line / end_line，没有就用缩进粗判）有交集同上黄 Needs re-check 说法还对不对只把黄、红的步骤，连同 diff，交给 Verifier（F1 第 2 节）；它可以建议改哪几步，由原作者或你接受你点 Re-check，或集群里 Reviewer 审到这个任务时Confirmed / Wrong / Unsure
前两档是机器、几乎零成本，不打扰你；第三档花 token，只在你点或集群审查时做。锚点和 diff 映射的实现和 D1 共用一层（D1 的实验：过 100 个提交后，原行号还对的只剩 3%，按 diff 挪能找回 94%）。
3 · 集群里：Reviewer 和 QA 怎么用
角色拿到什么做什么交回什么、显示在哪 调度器任务的 diff、项目里存的图（docs/flows/）算“动到的流程”：哪些图有锚点落在改动块里，是哪几步；跑前两档检查任务卡片上的 FLOWS 一行（C2、C3）；关卡卡片上一行（C4） Lead任务表草稿拆任务时可以先让人画要动的那条流程，任务的完成标准里写“flow X 第几步改成…”任务表里引用图的步骤 Reviewerdiff + 动到的流程和步骤 + 前两档的结果按图核对这次改动：改动后图上的说法还成立吗？要不要改图？（就是 Verifier 的那套，只看动到的步骤）审查结论里多一节 Flows；说错的步骤让任务回到实现者，连图一起改 QA动到的步骤 + Tests、Requirements 两层跑这些步骤相关的测试（Run tests for this flow）；看跑到的步骤有没有断言；对没有 TC 管的步骤提新用例验收汇报里的 “Not run / Not loaded” 步骤表和建议的 TC Worker—不用。可以 show 图来理解代码，不能交核对结论—

4 · agent 用的命令（走 agentdeck 命令行，不加 MCP 工具） 
agentdeck flow list                          flows in this project (docs/flows + drafts)
agentdeck flow show <id> [--json]            print a flow with anchor states
agentdeck flow save <file.seq.json>          validate, check anchors, store as draft
agentdeck flow open <id> [--step 6]          open the Flow window next to this terminal
agentdeck flow check <id> [--against <rev>] anchors and changed functions only
agentdeck flow touched [--diff <rev>]        which flows and steps a diff touches
agentdeck flow cover <id> --tests [--e2e]    run related tests with coverage, overlay
agentdeck flow verdicts <id> <file.json>     submit review results (Verifier only)
照 C7 的决定：新能力不进 MCP（现有 11 个工具不动），做成 agentdeck 命令行；怎么写一张图（锚点规则、kind 的含义、粒度）写进自带的 flow skill，按需加载。 谁能用：list / show / save / open / check / touched 在 AgentDeck 的每个终端里都能用（只读或只写草稿，没有开 session 的能力）；verdicts 只认 AgentDeck 开的 Verifier 子 session（按每个终端自己的钥匙 AGENTDECK_TERM_KEY 认，CR14）；cover 会跑测试，第一次在这个项目里跑要你点一次同意。这些命令都不能开终端、不能批准、不能提交、不能合并。 图先存成草稿（AgentDeck 数据目录）；你点 Save to repo 才写进仓库的 docs/flows/<id>.seq.json，AgentDeck 不提交。
