N6 · 白板平移手势先调研DR-53

要的效果：两指滑动永远给终端（滚历史），平移白板换一个不冲突的手势。限制：macOS 的“三指拖移”是系统辅助功能，传给应用的就是普通的按住拖动，应用分辨不出是几根手指，也拿不到原始的三指事件。

候选说明 空白处按住拖动在白板空白处拖动就平移；开了系统“三指拖移”的人，三指在空白处一拖就是平移（就是用户想要的手感） 按住空格拖动在窗口上面也能平移（设计工具的习惯）；终端聚焦时空格要留给终端，只在没聚焦时生效 两指只在空白处平移鼠标在窗口上时两指给窗口，在空白处时平移白板（现在的做法要核对） 捏合缩放，不变
N7 · 工作区和目录：终端 cd 出去了怎么办待定IS-57

工作区 = 一个 worktree + 一个分支；终端在框里打开时进的是这个目录。可是用户可以在终端里 cd .. 再开 claude，它就在框外的目录干活了，框的分支、源代码管理面板都对不上。要不要把 agent 强制绑在工作区目录里？

做法代价 提示（建议）tmux 能读到终端当前目录：离开工作区目录时标题栏出现灰色 “outside workspace”，面板跟着显示那个目录的仓库；不拦用户 强制在 agent 启动参数里锁目录（claude 的 --add-dir 等），shell 里 cd 拦不住，只能管 agent 不管框只是“从哪开始”，以后按终端实际目录分组
