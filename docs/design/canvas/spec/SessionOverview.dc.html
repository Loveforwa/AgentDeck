S2 · Session、长期运行、记忆：合成一个需求

2026-10-29 提议，待你确认

三件事是同一件事的三面。Session 是骨架：谁在做、在哪做、从哪来，关掉以后还在（S0、S1）。长期运行是 Session 的一种跑法：排好一串事，它自己一件件往下做，做没做完由 AgentDeck 跑检查说了算（W0、W2）。记忆让一条 Session 跨过 /clear、额度、交接、重开以后还接得上，也让新开的 Session 一开始就知道这个项目的坑（S3、W1）。原来它们分在两页，记忆散在三处：W0 的“进度记在队列里”、W1 的 Lessons、DR-74 的“偏好和进度归各家”，而且互相打架；W0 的队列还挂在已经退役的 PL3 卡片上。这一页把它们合起来：先讲关系，再讲改了什么、分几期、任务表怎么跟着改。

4 · 分期
