4 · “照着视频做出一个一模一样、测过的 skill”是什么意思
#视频里视频里做了什么照着做出来对得上吗 103:12每个任务开一个 worktreegit worktree add 成功，截图里的目录一样Matches 207:40先写 plan.md 再改代码plan.md 写出，结构和视频里三节一样Matches 613:20用 --fast-mode 起第二个 agent这个参数现在报错 unknown option；换成设置里打开Differs 919:02连到一个付费的服务没试：要账号Not tried …还有 7 步
我们理解的是：视频里演示了一套做法，agent 把它写成一个 skill（SKILL.md 加脚本），然后在容器里真的照着跑一遍，每一步截图或记输出，和视频的关键帧并排比。所以“一模一样”是逐步对照，不是像素级一样。这个理解对不对，要你确认。 谁判对不对：另一家 agent 看每一对截图和输出，给 Matches / Differs / Not tried，必须带证据（截图或输出的那一行）；界面上的差别可以加一个图像差异做参考。 skill 里记来源：视频链接和每一步的时间点；这次跑的对照表存成这个 skill 的测试，以后可以再跑一遍看还对不对（比如工具升级以后）。 进 Skill 库（K0）要你 Accept；Differs 的步骤写进 skill 的说明里（“视频里的参数已经没有了，改用……”）。
