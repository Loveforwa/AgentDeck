什么时候出：集群跑完、你点 Stop、或者你点集群框上的 Report 看到目前为止的。集群跑完时收件箱多一条 “Ready to merge”。 写什么：每个任务谁做的、来回几轮、检查过没过、改了多少；agent 用 agentdeck crew note 记下的发现；没解决的问题；每家的用量（来自 PL2 Usage）和因为额度停了多久。 Decisions：你在收件箱和关卡上做过的每个决定（和谁给的建议）。这些是集群的“短期记忆”，不写进仓库；值得长期留的（比如“恢复会话一律在原来的框里”）由你自己抄进 AGENTS.md，AgentDeck 不替你写。 Merge into main：最后一道关卡，永远由你点。也可以 Create PR，汇报原样当 PR 描述（Copy as Markdown）。 汇报存在 AgentDeck 的数据里，随集群一起留着，左边栏历史里能找回。
