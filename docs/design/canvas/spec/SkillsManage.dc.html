K0 · 大批量 skill：一处看全，按项目减掉，换一家不用重装

2026-10-28 已定（按推荐）

你手上一百多个 skill 散在 claude、codex、pi、omp、kimi 各自的目录里，每个的描述每轮都进上下文。AgentDeck 不去改这些目录，只做三件事：把各家目录读出来放在一张表里（谁装了什么、哪些重名、哪些副本已经不一样、每家每轮多少 token）；按项目决定 AgentDeck 开的终端里带哪些、其余的“只给名字”或“关掉”；库里的 skill 由 AgentDeck 在启动时带给每一家（N9 的办法），换一家 agent 不用重装。

规则和 N9 一样：只通过启动参数和环境变量，只影响 AgentDeck 开的终端；改了以后 Restart and resume 生效。你在系统终端里直接开的 claude 不受影响。

顶上一排：每家一块，agent 身份色只用在小方块上。写这家在 AgentDeck 开的终端里会看到几个、每轮大约多少 token。claude、codex 超了自己的预算时写 “Descriptions cut to fit”（等你的黄色字：模型会选不中）。

表：按名字合并。Found in 写在哪些目录，软链写 (link)，独立副本写 (copy)。五列写这家看不看得到：✓ 看得到；· 不在它会读的目录里；manual 是 disable-model-invocation，描述不进上下文；n/a 是这家带不了（codex 加不进库里的 skill）；— 是坏的（没有 SKILL.md、frontmatter 读不出）。

筛选：Duplicates 同名出现在两处以上；Copies differ 同名但内容不一样（说明有一份过时了），Est. 一列写 differ；Not found by claude 在 ~/.agents/skills 这类 claude 不读的目录里。

⋯ 菜单：Add to library 把它复制进 AgentDeck 的库（之后能带给任何一家）；Compare copies… 并排看两份的差别；Reveal in Finder 让你自己去整理。没有删除、没有移动，AgentDeck 只读这些目录。

在项目页里加一节，不另开对话框（SettingsDialog 的 128px 标签栏、Field、RadioGroup 照用）。

Library skills：这个项目里 AgentDeck 开的终端默认带哪些。和 N9 的面板勾选是同一份选择，面板上还能按终端再改。

Other skills in your agent folders：各家自己目录里的那些（~/.claude/skills 等）。默认 Leave as is，和现在一样。选 List names only 时，claude 用它自带的 name-only，其他几家没有这一档，按 Turn off 处理并写明；Keep these… 里的照常带。

估算：改前 → 改后，写在旁边，让你知道减了多少。不支持的那一档写原因，不悄悄退回。

存哪：项目设置（settings.json 里这个项目的 skills），不往仓库写。全局默认在 Settings › Skills 底部有同样一组（没画）。

4 · 规矩
只读用户目录~/.claude/skills、~/.agents/skills、~/.codex/skills、~/.pi/agent/skills、~/.omp/agent/skills、~/.kimi-code/skills 和仓库里的 skill 目录只读，不写、不删、不搬、不建软链。要整理请自己动手（Reveal in Finder）。
只影响 AgentDeck 开的终端加法用 N9 的 setDir，减法用各家的启动参数（K1 第 3 节）。你在系统终端里开的 agent 和以前一样。
三层Settings › Skills（全局默认）→ Project settings › Skills → 面板上的这个终端。集群角色是开终端时套上的一套选择。
不支持就写原因codex 加不进库里的 skill，也没有 Names only；不支持的格子灰掉写原因，不悄悄换成别的做法。估算一律写 “~”。
