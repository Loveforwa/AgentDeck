PL3 · Prompt queue：额度用完后，到点接着发你排好的提示词

2026-10-27 定 PL3 · IS-88 · DR-63

5 小时额度用完了，你还有很多想法要它做。在 agent 终端上开 Prompt queue，先把提示词一条条排进去；这个终端的 agent 碰到额度上限时，插件按 agent 自己记下的恢复时间到点（多等 1 分钟）把第一条发进去，它做完一轮回到空闲再发下一条；又碰到上限就等下一次恢复，发完为止。你不在电脑前也能接着跑。

5 · 规则
情况怎么做 什么时候发第一条这个终端的 agent 碰到额度上限（5 小时或每周），并且到了记录里的恢复时间 + 1 分钟，并且 agent 空闲。 什么时候发下一条上一条那一轮做完、agent 回到空闲（状态机的 turn-end）。中间你自己打了字，就等你这一轮也做完。 怎么发和批准一样走终端的按键（tmux send-keys）：先把文字送进输入框，再按回车。多行的按 agent 自己的多行写法送。 不发的时候在跑、等你批准、等你回答、终端退出了、你点了 Pause、应用关着、电脑睡着。应用重开后按保存的队列接着等。 恢复时间读不到不猜：书签写 “Limit reached · reset time unknown”，等你点 Send next now。 记录每发一条记下时间和内容（卡片里能看），提示词只存在白板里，不写进 agent 的配置。
