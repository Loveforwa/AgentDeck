条上写什么
字段意思 Input这次对话累计发给模型的 token（不含缓存） Output模型累计写出来的 token（含思考） Cache模型从缓存里重读的 token（便宜、快）。缓存写放在悬停里 Context当前上下文用了多少 / 窗口多大，占比和一根小进度条，写法照 agent 自己的（kimi 的 k 按 1024、百分比向上取整；codex 先扣 12000 的基线），和终端里看到的一致。到 85% 时数字和进度条变黄（“需要你处理”：该压缩或开新对话了）

读不到数据的写 “No usage data”，不瞎估。数字用 k / M 缩写，悬停看准确数和模型名。
