4 · 不越记越乱
1. 只记确定的事：AgentDeck 不读 agent 屏幕上的话来“理解”进度；能记的只有它自己派的活、跑的检查、git 的提交、收件箱里的回答、LimitService 的额度、交接。 2. agent 只能补，不能改：agentdeck note "…" 只追加一条 NOTE，标来源；改和删只有你能做。 3. 有上限：brief ≤ 600 token；笔记本身不设上限，但 brief 只取 GOAL、最近的 DECIDED、BLOCKED、NEXT 和 DONE 的计数。 4. 跟着 Session 走：交接、fork 时复制给子 Session（标 “from parent”），之后各记各的；Session 删了笔记一起删；不跨项目。 5. 和 Lessons 分开：笔记是“这条线的事”，到了晚上就过时；Lessons 是“这个项目下次还会碰到的坑”，要你 Accept。BLOCKED 那一条可以一键 “Propose as lesson”，进 W1 的候选。 6. 和各家 memory 不打架：AgentDeck 不读不写 ~/.claude、~/.codex 下的 memory；偏好照旧写 AGENTS.md。
