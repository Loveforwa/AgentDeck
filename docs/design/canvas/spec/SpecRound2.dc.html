V3 · 窗口和框互不遮挡，拖动时有对齐线IS-53 IS-54

像画图网站（Figma、tldraw、Excalidraw）那样：拖动或改大小时，靠近别的窗口边缘、中线、相同宽高就吸过去并画出对齐线；松手时不允许和别的窗口重叠，也不允许两个工作区框重叠。实现前先调研这些工具的吸附和避让做法（DR-52），不自己从头摸索。

工作区框也一样：拖到别的框上会停在边上（保持 20px 间距），不会盖住别人。所以“盖住后把终端误判成要换框”（IS-54）也不会再发生。

规则说明 吸附距离屏幕上 6px 以内吸住（随缩放换算成白板坐标）；按住 ⌘ 拖动临时不吸。 对齐对象同一个框里的窗口、框的内边、相邻的框；对齐边、中线、等间距、同宽同高。 避让只在松手时处理：找离松手位置最近、放得下的空位；放不下就把框撑大（框跟着长，已有规则）。不推动别的窗口。 框和框框之间至少 20px。拖框时碰到别的框就停在边上；框跟着窗口长大时，挡在路上的框整体往外挪。 放大放大的窗口（⌘⇧↩）例外，可以盖住同一个框里的其他窗口，还原后回到原位。
