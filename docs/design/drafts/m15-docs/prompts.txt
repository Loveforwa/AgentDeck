==== 3. agentdeck doc 命令（给 agentdeck-docs skill 和 /cli 用，依赖 CR13–CR15） ====
所有 AgentDeck 终端都能用（不像 crew / session 命令只给 Lead）：只读或只改文档本身和评论，不能开终端、不能批准。

agentdeck doc open <path> [--at <heading|line>]      打开文档窗口，放在调用者旁边，linkedTerminal = 调用者
agentdeck doc check <path>... [--fix-lines] [--json]  核对引用；有 gone / ambiguous 时退出码 1，有 changed 时 2；--fix-lines 只改 moved 的行号
agentdeck doc comments <path> [--all] [--json]         列出评论：id、挂的字、内容、谁写的、状态
agentdeck doc reply <id> "<text>" [--done]              回复；--done 把它标成 Addressed（不 Resolve）
agentdeck doc claims <path> [--json]                    核查用：列出要核查的句子和引用
agentdeck doc verdict <claim-id> <result> "<reason>" [--fix "<text>"]   只有核查终端能调（按钥匙认，CR14）
